# packages/prompts — versioned templates

`claimsight_prompts.templates` (`POLICY`, `NECESSITY`, `FRAUD`, `SUPERVISOR`, `COMPLIANCE`, `INTAKE`) plus `PROMPT_VERSION`.

Change prompts in the same PR as eval regressions.

Env override: `CLAIMSIGHT_PROMPT_VERSION`.

## What this is not

Not a prompt CMS. Git is the registry.
